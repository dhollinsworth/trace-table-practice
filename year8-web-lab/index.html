The big project
Your idea. Your website.
Create a page about a hobby, a fictional club, an animal or a place. Use made-up details rather than personal information.
Choosing a starter replaces your project after confirmation. Your project saves automatically in this browser.
YOUR WEBSITE PREVIEW
Aim for: a title, one main heading, two paragraphs, a list, a useful link, an image with meaningful alt text, and CSS styling.
Stretch: add a second section with an id and a navigation link to it. Improve spacing, colours and readability.
Download creates index.html. Open it in a browser to view it, or in a text editor to continue coding. Downloading does not publish it online. Submit the file as your teacher directs.

The code toolkit
HTML gives a page structure and meaning. CSS controls how it looks. A browser reads both to display your webpage.
When something goes wrong
Check matching opening and closing tags, quotation marks around attributes, and CSS braces and semicolons. Change one thing at a time and inspect the preview.
