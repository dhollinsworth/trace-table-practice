Complete the trace table

Input data: 2, RACECAR, TREAT

Trace the variables in the given column order. Stay on the same row when the next entry is to the right; start a new row when it is in the same column or to the left. Record every input and assignment, including repeated values. Leave unused cells and spare rows empty.

SUBSTRING positions start at 1. Enter letters and output text without quotation marks. For this exercise, record Index at the start of each executed FOR iteration (1 and 2); do not add a final out-of-range value of 3.
How the algorithm works

RACECAR compares R/R, A/A and C/C. V1 and V2 then both reach 4, so the WHILE loop ends without comparing the middle E. Continue is still TRUE and the output is Successful.

TREAT first compares T/T, then R/A. The mismatch sets Continue to FALSE. V1 and V2 remain 2 and 4, and the output is NOT successful.

Number is input only once. Index changes for the second word, and Continue is reset to TRUE at the beginning of each word.
